## 3. Verifying curated wraps (reduced scope)
Scripted pre-publish check (CI or local, e.g. Python/Pillow): PNG magic bytes `89 50 4E 47 0D 0A 1A 0A`; dimensions equal the target template size (1024x1024, CT 1024x768) and within 512–1024; file ≤ 1,048,576 bytes (treat "1 MB" conservatively, Tesla doesn't define MB vs MiB — UNVERIFIED); filename regex `^[A-Za-z0-9_\- ]{1,30}\.png$` (whether ".png" counts toward 30 is UNVERIFIED); strip metadata via re-encode (oxipng/pngquant to stay <1 MB). Plus a manual in-car smoke test per model. Evidence the size check matters: a gallery's wraps exceeded 1 MB and didn't show in car — https://www.reddit.com/r/TeslaLounge/comments/1prtm0p/tesla_wrap_design_community_gallery_with_online/

## 5. Legal/IP risks (not legal advice)
- Tesla notice: all marks incl. model name plates, logos subject to Tesla rights; site content grants no licence: https://www.tesla.com/en_gb/legal/additional-resources (snippet via search; direct fetch 403). A dedicated public "trademark guidelines" page was not found.
- Name "tesla-wrap-workshop": domain incorporating the whole TESLA mark is generally treated as "confusingly similar" under UDRP (https://www.domaintimes.info/post/what-is-confusingly-similar); but a UDRP panel denied Tesla on teslaunch.net for lack of bad-faith evidence (https://www.adrforum.com/DomainDecisions/2120768.htm). Risk: medium; many competitors use "tesla" names openly. Mitigate: nominative use, prominent "not affiliated" disclaimer (cf. https://modtesla.com/pages/disclaimer), no Tesla logos/fonts, or a name without "Tesla".
- Template licensing: no licence → redistributing template.png/example images/vehicle_image.png is not granted. Designs derived from the template UV layout — derivative-work status unclear, HIGH-uncertainty, flag for counsel. Linking to the Tesla repo instead of rehosting is the low-risk path.
- Secondary (no uploads in v1): if uploads come later, need DMCA designated agent (https://www.copyright.gov/dmca-directory/), takedown/counter-notice flow, repeat-infringer policy; EU DSA notice-and-action. Curated content still carries copyright risk if we publish third-party art/logos (e.g. Batman fan wraps).
